# BAITUNA — Satu Masjid, Banyak Manfaat
Platform digital ekosistem masjid Indonesia. Stack: HTML, CSS, JavaScript modular, PWA, Supabase, Vercel.

## Jalankan lokal
    cd baituna
    python3 -m http.server 8000
Buka http://localhost:8000 (service worker butuh localhost atau HTTPS).
